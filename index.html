How it works

Simple static hosting, no build step

1. Mirror the JSON feed

The GitHub Action downloads the public events.json file and saves it into this repo.

2. Generate ICS

The Node script converts the JSON into a timezone-aware calendar.ics export.

3. Publish to Pages

GitHub Pages serves this dashboard plus the generated ICS file directly from the repo.
