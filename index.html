How to subscribe:

  1. Copy the URL for your class above
  2. Open Google Calendar → Other calendars (+) → From URL
  3. Paste the URL and click Add Calendar

Google/Apple Calendar may take up to 24 hours to refresh. For the latest, use the Calendar view or download the ICS directly.

How It Works

This site mirrors the official EnMed calendar and generates stable ICS feeds that external calendars can subscribe to.

1

Events are updated

The PreClerkship Team updates the master calendar. A GitHub Action syncs new events every 30 minutes.

2

ICS feeds are generated

Separate .ics files are built for the full calendar and each class (M0, M1, M2) so you only see what's relevant to you.

3

Your calendar refreshes

Subscribed calendars (Google, Apple, Outlook) automatically pull the latest version — no action needed from you.
